# My Engineering Playground 🚀

This repository is my long-term personal workspace and knowledge base for mastering software engineering, modern frameworks, and DevOps tools.

## 🎯 Purpose
- **Frameworks & Core Python:** Deep-diving into asynchronous programming, FastAPI, and Django architectures.
- **Databases:** Studying optimization, indexing, and complex scenarios in PostgreSQL, MySQL, and NoSQL solutions.
- **DevOps & Cloud:** Practicing local orchestration with Docker, transition to Kubernetes, and automating deployments.
- **Problem Solving:** Tracking my algorithmic progress with structured LeetCode and interview tasks.

## 🛠️ General Rules
- **Isolation:** Every app has its own isolated environment and dependencies.
- **No Secrets:** All database passwords and keys are strictly stored in local `.env` files and never pushed to GitHub.
- **Automation:** All main actions are simplified via short commands in the root `Makefile`.
